# Прототип двух агентов для корпоративных задач Битрикс24

Система на Python извлекает действия и результаты из истории задач, сохраняет проверенные человеком записи и готовит черновик ответа на новую задачу. Первый агент анализирует прошлые задачи, второй использует проверенную память. Для вызовов языковой модели используется YandexGPT; локальный поиск работает через SQLite FTS5.

## Что реализовано

- Импорт задач и комментариев из ZIP-выгрузки в локальную SQLite-базу.
- Черновая разметка действий моделью, проверка человеком, связь с исходным комментарием и отзыв подтверждения после изменения источника.
- Отдельная классификация действия как решения, события сопровождения или неясного случая. Исполнитель использует только подтверждённые успешные решения.
- Сравнение трёх вариантов контекста для одного исполнителя: исходные тексты, резюме и проверенная память.
- Локальный адаптер чтения одной задачи и её чата через REST Битрикс24. С рабочим порталом он ещё не проверен.
- Команды подготовки контекстов и запуска модели, а также локальное окно слепой оценки.

Текущие ограничения и результаты описаны в [протоколе эксперимента](docs/EXPERIMENT.md). Прототип не доказал превосходства проверяемой памяти: после исключения организационных событий подтверждённый опыт нашёлся только для одной из десяти новых контрольных задач.

После проверки черновика опыта его нужно отдельно классифицировать. Например, для записи, которую проверяющий действительно признал решением:

```powershell
python -X utf8 -m bitrix_agents reviews --task-id ID_ЗАДАЧИ
python -X utf8 -m bitrix_agents classify-review --review-id ID_ЗАПИСИ --kind solution --reviewer "ФИО проверяющего"
```

Возможные типы: `solution`, `administrative`, `unknown`. Старые подтверждения по умолчанию имеют тип `unknown` и не становятся решениями автоматически. Не ставьте `solution` только потому, что задача завершена или в комментарии обещали выполнить действие.

Листы с исходными комментариями и черновиками разметки создаются локально в `data/` и не входят в репозиторий.

## Быстрый запуск

Откройте папку проекта в PyCharm с Python 3.11+ или выполните в PowerShell:

```powershell
python -X utf8 -m bitrix_agents demo
python -X utf8 -m unittest discover -s tests -v
```

Демонстрация использует вымышленные данные и не требует ключей. Для локальной работы с реальной выгрузкой:

```powershell
python -X utf8 -m bitrix_agents import --archive "ПУТЬ_К_ВЫГРУЗКЕ.zip"
python -X utf8 -m bitrix_agents stats
python -X utf8 -m bitrix_agents search --query "текст задачи"
```

База создаётся в `data/tasks.sqlite3`. Вся папка `data/` исключена из Git: не публикуйте её, выгрузку, файл `.env` и реальные ответы модели.

## Первое сравнение на десяти задачах

Первый набор из десяти задач и ответы старой версии сохранены в `data/prototype_10/`. Эти результаты не меняются после доработки памяти. Продолжить их человеческую оценку можно командой:

```powershell
python -X utf8 -m bitrix_agents review-gui --results-dir data/prototype_10
```

## Повторение сравнения на своих данных

После проверки содержательных решений в прошлых задачах выберите **новые** контрольные задачи. Не используйте уже просмотренные наборы как независимую проверку изменённого метода. Предварительно просмотрите подготовленные тексты, затем укажите свой файл настроек по образцу `.env.example` и новую папку результатов:

```powershell
python -X utf8 -m bitrix_agents prototype-preview --task-ids ID1 ID2 ID3 ID4 ID5 ID6 ID7 ID8 ID9 ID10 --k 3
python -X utf8 -m bitrix_agents prototype-run --task-ids ID1 ID2 ID3 ID4 ID5 ID6 ID7 ID8 ID9 ID10 --k 3 --env-file .env --results-dir data/prototype_v2
python -X utf8 -m bitrix_agents blind-review --results-dir data/prototype_v2
python -X utf8 -m bitrix_agents review-gui --results-dir data/prototype_v2
```

Запуск модели делает платные сетевые запросы. Новая версия метода должна использовать **новую папку результатов**: старые ответы нельзя выдавать за результаты изменённой памяти. Последняя команда открывает локальное окно оценки; интернет для него не нужен. В окне показываются варианты A, B и C без названий методов. После каждого сохранения оценка записывается в `data/prototype_v2/blind_ratings.json`; при повторном запуске прогресс восстанавливается. Ключ методов хранится отдельно в `method_key.json` — не открывайте его до окончания оценки. Результаты остаются в исключённой из Git папке `data/`. Само наличие десяти ответов не означает, что качество уже установлено.

## Основные модули

| Файл | Назначение |
|---|---|
| `bitrix_agents/core.py` | Контракты и двухагентная оркестрация |
| `bitrix_agents/local_archive.py` | Импорт и постоянное хранение задач и разметки |
| `bitrix_agents/prototype.py` | Подготовка контекста и сравнение трёх методов |
| `bitrix_agents/yandex.py` | Вызов YandexGPT |
| `bitrix_agents/experiment.py` | Оценка поиска по экспертным меткам |
| `bitrix_agents/bitrix_api.py` | Чтение задачи через REST Битрикс24 |

Настройки и корпоративные данные не включены в репозиторий. Коннектор читает только задачу, доступную указанному вебхуку; проверка прав и подключение к реальному порталу остаются отдельной задачей.
